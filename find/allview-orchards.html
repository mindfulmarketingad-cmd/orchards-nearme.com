We came first time there. 1. A lot of signs saying no transparent, no parking, we are recording you. It was really confusing if we were welcome there or not. So, for the first comers, don't be confused. Just drive up to the hill and find Deborah. 2. Cherry was really good, but I think it is overpriced. For the small bag, we paid $20 (for the box $120). We finished them super quick, and then I bought the same cherry from Smallwoods market for $12 (2 pictures from for comparison attached). 3. We couldn't pick up cherries because workers were there on Sunday. So, if you're planning to pick up cherries, make sure to call first and see if you will be able to do it.
